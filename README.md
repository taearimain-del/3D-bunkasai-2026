# 3D-bunkasai-2026

3年D組 文化祭公演「アナと雪の女王」の台本・資料管理リポジトリ。

## 資料を見る

配布資料の一覧・最新PDFはこちら:
**https://taearimain-del.github.io/3D-bunkasai-2026/shiryo.html**

企画書・配役表・舞台構成・台本（完全版／役者用）・係別役割書へのリンク、変更履歴、質問コーナーをまとめてあります。

本番用の音響再生ツール（音源内蔵・PWA対応）は上記ページ内、またはリポジトリトップの自動転送先から開けます。

## フォルダ構成

```
生徒用/
  pdf/        配布用PDF（正式版）
  html/       ブラウザ確認用HTML（pdfと同内容）
  音響ツール/  本番用の音響再生ツール一式
  変更点.md    変更履歴
other/         各資料のMarkdownソースと完成版HTML（編集はここ）
過去版/         上書き・削除前の旧版アーカイブ
プロジェクト概要.md   基本情報・運用ルール・引き継ぎ情報（作業前に必読）
```

詳細は [`プロジェクト概要.md`](プロジェクト概要.md) を参照。

## 資料の更新の流れ

1. `other/` 配下の `.md` ソースを編集
2. `md_to_html.py` でHTML化 → `chrome_print.mjs` でPDF化
3. `生徒用/pdf/`・`生徒用/html/` に反映し、`生徒用/変更点.md` に記録

具体的なコマンドは [`プロジェクト概要.md`](プロジェクト概要.md) の「PDF再生成手順」を参照。
