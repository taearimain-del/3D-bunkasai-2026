# 大道具係
## 役割書 — 大道具係

---

## 概要・責任範囲

大道具係は**セット（背景・大型の舞台装置）の制作・設置・場面転換**と**教室装飾**を担当する。
公演当日は暗転中に素早くセットを入れ替える必要があるため、転換フローを全員で把握しておくこと。

---

| 人数 | 役割 |
|------|------|

| 2〜3人 | 制作・塗装作業 |

## 本番の場面転換フロー

暗転中に速やかに動く。演出または舞台監督の合図（手信号）で動き出すこと。

| タイミング | 転換内容 | 担当 |
|-----------|---------|------|
| ACT1→ACT2（雪だるまつくろう後） | 戴冠式用の背景・小道具を配置 | 大道具係＋役者（ハンス役・公爵役など） |
| ACT2→ACT3（とびら開けて後） | 転換なし（茶系背景パネルはそのまま継続使用） | 大道具係 |
| ACT3『レット・イット・ゴー』**開始時** | 白・水色の布/パネルを後方に展開（雪山・氷の城を表現） ※暗転ではなく歌の始まりに合わせて出す | 大道具係 |
| ACT3→ACT4（レット・イット・ゴー後） | 白・水色パネルを撤去するのみ（ドアフレームは廃止済みのため搬入不要） | 大道具係 |
| ACT4→ACT5（あこがれの夏後） | 氷の城背景パネル（白・水色）を前面に設置 | 大道具係 |
| ACT5内『エルサの城→トロールの村』（2026-08-07新設の短い暗転） | 氷の城パネル（白・水色）を撤去→トロール村パネル（緑系）に架け替え。ハトメ＋カーテンリング（またはS字フック）でワイヤーに掛ける方式。目安15〜20秒（ゲネプロで計測） | 大道具係2名 |
| ACT5→ACT6（ハンスの部屋へ、45秒暗転） | 氷の城パネル（白・水色）を撤去→茶系背景パネルに切替（4名体制・目安25秒）、机・椅子を搬入（2名・目安15秒）。**机・椅子は暗転前に上手袖の奥に事前スタンバイ**（大人エルサの退場経路より奥に待機させ、エルサ通過確認後に引き出す）。搬入動線は上手一方向に固定。35秒時点でパネル切替未完了の場合は延長合図（舞台監督が手を2回叩く）。**ゲネプロで必ず計測・記録すること**。 | 大道具係 |
| ACT6内（クライマックス前・短い暗転） | 机・椅子を舞台袖へ素早く撤収。茶系背景パネルはそのまま残す（城の外壁として転用） | 大道具係 |

## 役者との連携

出番の少ない役者が場面転換を手伝う。事前に動きを確認しておくこと。

| 役者 | 手伝えるシーン |
|------|-------------|
| ウェーゼルトン役 | ACT4以降の転換（ACT3で退場後）。**フォールバック**：トロール役の衣装脱ぎがゲネプロで20秒以内に収まる場合は不要。収まらない場合、ACT5→6の机・椅子搬入（2名分）をウェーゼルトン役2名（こたに・しゅうた）で分担する |
| トロール役 | ACT1〜3の転換（計3回担当）。ACT3→ACT4転換はドアフレーム廃止に伴い大道具係のみで対応可能なため対象外。ACT4→5転換もACT5登場準備に専念のため除外。**ACT5→6転換（45秒暗転）も兼務**：ACT5『トロールの村』出演後、衣装を素早く脱いで大道具作業（机・椅子搬入）に加わる（2026-07-04追記） |

### トロール役の衣装即脱ぎ設計（2026-07-04追記）

トロール役はACT5終演直後にACT5→6転換（45秒暗転）で大道具作業を兼務するため、衣装を舞台袖で素早く脱げる設計にすること。

- **衣装仕様**：上から羽織れるケープ・ベスト・腰布タイプ（岩・森を意識したデザイン）。スナップボタンまたは面ファスナーで留め、**2〜3秒で脱げる**ようにする。下には黒Tシャツ＋黒ズボンを着用しておき、脱いだ瞬間に大道具スタッフの見た目になる。
- **ゲネプロでの確認**：「脱ぐ→移動→パネル搬出完了」までの一連の流れを**20秒以内**に収められるか、必ずゲネプロで計測すること。**20秒以内に収まる場合はフォールバック不要。**
- **フォールバック案**：20秒以内に収まらない場合は、ウェーゼルトン役2名（こたに・しゅうた）で机・椅子搬入を分担する（上表参照）。ウェーゼルトン公爵のダブルキャストが2026-07-10に確定したため、当初案どおり「ウェーゼルトン役2名」プランで運用する。

## リハーサルで確認すること

- [ ] 各セットが暗転中に1分以内で転換できるか確認
- [ ] 背景パネルの固定方法（立て掛け・壁への取り付け等）を決めておく
- [ ] 転換中に音を立てないよう練習する
- [ ] ACT5→6転換の作業時間をゲネプロで計測し記録する（45秒以内に完了できるか）
- [ ] 机・椅子の事前スタンバイ位置（上手袖の奥・エルサ動線より内側）を確認する
- [ ] 延長合図（手を2回叩く）の意味を全員で共有する
- [ ] トロール役の衣装即脱ぎ（「脱ぐ→移動→パネル搬出完了」20秒以内）をゲネプロで計測する。収まった場合はフォールバック不要。収まらない場合はウェーゼルトン役（こたに）＋バックアップ生徒1名への分担に切り替える
