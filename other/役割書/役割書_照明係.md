# 照明係
## 役割書 — 照明係

---

## 概要・責任範囲

照明係は**公演中のすべての照明操作**を担当する。
舞台監督の合図に従い、台本の 💡 マークのタイミングで照明を切り替える。
ミスると観客にバレるため、事前のリハーサルで操作を徹底的に練習すること。

---

## 必要人数・役割分担

| 人数 | 役割 |
|------|------|
| 1人 | メイン操作（学校の照明パネルを担当） |
| 1人 | 演出補助・タイミング確認（台本を手元に持つ） |
| 1人（余裕があれば） | スポットライト担当（ある場合のみ） |

**目安：2〜3人**

---

## 準備物チェックリスト

- [ ] 照明パネルの場所・操作方法を事前に確認する
- [ ] 色フィルター（青・水色・オレンジなど）：借用確定（入手済みまたは入手予定）。万一破損等で使えない場合の代替手順は下記「色フィルターのフォールバック運用」を参照
- [ ] このキューシートを印刷して手元に持つ
- [ ] ゲネプロ前にすべてのキューを通し練習する

## 照明カラーイメージ

| 場面 | 照明イメージ |
|------|------------|
| 通常の室内・野外シーン | 暖かいオレンジ・黄色系（白昼光でも可） |
| 氷の城・魔法シーン | 冷たい青・水色系 |
| ハンス裏切り告白 | 暗め・冷たい青（通常より暗くする） |
| 春の到来・フィナーレ | 最も明るい暖色 |
| 暗転（場面転換） | 完全消灯 |

## 色フィルターのフォールバック運用（2026-07-05追加）

> 色フィルター（青・水色・オレンジなど）は借用確定済み。以下は万一当日に破損・紛失などでフィルターが使えなくなった場合のための保険的な代替運用（キューシートの「フィルターなし代替」列と対応）。

| 推奨カラーの系統 | フィルターなし代替指示 |
|----------------|----------------------|
| 冷たい青・水色系 | 蛍光灯全点灯（明るく冷たい印象） |
| 暖かいオレンジ・黄色系 | 蛍光灯1/2消灯＋スポット集中（暖色寄り） |
| 暗転 | 変わらず全消灯 |
| 明るい白系（通常照明で代用可能なもの） | 対象外（フィルター不要・通常の蛍光灯でよい） |

## 役者との連携

- 出番のないシーンの役者（ハンス役・ウェーゼルトン役など）が照明補助に入ることがある
- 照明操作は必ず照明係メンバーが行う。役者が代わりに操作しない
